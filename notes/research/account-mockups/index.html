Log in

Empty

The cursor starts in the name. Tab moves on, Enter logs in, Esc goes back. No key letters here: letters are text.

Filled in

Ready: Enter logs in.

Working…

While the key is made from the password (PBKDF2, in a Web Worker): about a second on a desktop, several on a phone. A slow, even bar and a sentence that says how long. WebCrypto gives no real progress, so the bar runs on the time the device took last (or a first guess).

Wrong name or password

One message for both. The password is cleared and has the cursor; the name stays.

After three failures

The Turnstile box comes in above the button (300 × 65, Cloudflare’s own drawing; here a placeholder).

15-minute wait

Ten failures for one name in 15 minutes. A countdown, and the reason in plain words. The same is shown for a name that does not exist.
