Sync mockups, round 9 (stage 61)

Throwaway mockups for the seven points of stage 61 (sync of profiles and scripts, the two spaces), in the real look: the start page, the Account page, its dialogs and the Profile page as captured from a dev server, the new parts drawn over them. Each picture opens that state in the one file; there the tabs switch point, variant and state, and Desktop / Phone the view. README.md beside this file has each variant, a recommendation per point and what did not fit.

Everything in one file
