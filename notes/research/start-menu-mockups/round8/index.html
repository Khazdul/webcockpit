Start menu mockups, round 8 (stage 67)

Throwaway mockups of the new start menu (three zones, the owner row) and of History with its tab strip, in the real look (the pages' own DOM and CSS, captured). Each picture opens that state in its file; there the tabs switch topic, direction and state, and Desktop / Phone / Landscape / Tablet the view. README.md beside this file has the directions, the recommendation for each of the seven picks and what did not fit.
